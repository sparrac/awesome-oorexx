## Style & Conventions

### Markdown Formatting
- **Indent**: 2 spaces
- **Charset**: UTF-8
- **Trailing whitespace**: Trimmed
- **Final newline**: Inserted
- Use descriptive link text (not "here" or "link")
- Include version compatibility or specification notes in parentheses, e.g., `(ooRexx 4.x)`, `(ooRexx 5.0+)` when relevant

### Link Requirements
- Links must be functional (no broken links)
- Excluded from link checking: instagram, linkedin, twitter
- Permanent redirects should be updated in source

## Contribution Guidelines

PRs should:
- Add valuable resources for Open Object Rexx users
- Focus on a single suggestion
- Include a link to the repository in the PR body
