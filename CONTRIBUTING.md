# Contributing

Contributions are welcome!

## How to Contribute

You can contribute in two ways:

- **Through an issue**: Suggest a new entry by opening an issue with the name, description, and link
- **Through a pull request**: Fork this repository, add the entry to the appropriate section in README.md, and submit a PR

## Contribution Criteria

Please ensure your contribution:

- Is specifically for Open Object Rexx
- Adds value to the community
- Has existed for at least one month
- Includes: name, clear description, and a working URL
- Is actively maintained OR confirmed to work in modern environments
- Follows the existing format and structure in README.md

**Note:** Projects compatible with both classic Rexx and Open Object Rexx should be listed in a separate curated list (`awesome-rexx`), which will be linked once it is available.

Thank you for your suggestions!

## Projects without a Stable Home

Some well-known Open Object Rexx projects are currently omitted because they lack a stable, standalone home. They may lack a dedicated project page, public repository, or maintained documentation, or they may only be distributed as part of a larger project.

Examples include utilities such as ooRexxUnit, ooTest, dbus4oorexx, jdorfx, log4rexx, and TraceTool. They can be added once a suitable canonical reference is available.
